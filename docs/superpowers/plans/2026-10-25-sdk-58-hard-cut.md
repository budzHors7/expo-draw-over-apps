# Expo SDK 58 Hard-Cut Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship an Android-only Expo SDK 58 module using Expo Modules 2.0 whose only supplied window components are `ReactNativeWindow` and `NativeWindow`, backed by one clear SDK 58 documentation path.

**Architecture:** Keep the existing overlay service, named-window state, and application-owned renderer registry. Replace the native module definition DSL with the SDK 58 annotated Kotlin API, replace the current mixed window-container implementation with two focused React wrappers, and make the example and docs demonstrate only those wrappers.

**Tech Stack:** Expo SDK 58, React Native 0.88, React 19.3, Kotlin/Expo Modules 2.0, `@expo/ui/jetpack-compose`, Reanimated 4.7, Worklets 0.13, TypeScript, Jest, Docusaurus, Android Gradle, adb.

**Spec:** `docs/superpowers/specs/2026-10-25-sdk-58-hard-cut-design.md`

## Global Constraints

- Android remains the only native platform.
- The release is a hard cut: no SDK 55/56/57 compatibility and no aliases for removed UI APIs.
- The only supplied window components are `ReactNativeWindow` and `NativeWindow`.
- `NativeWindow` renders a real Expo UI `Host`, defaults `matchContents` to true, and accepts Expo UI children directly.
- `ReactNativeWindow` retains Reanimated width, height, and radius transitions for React Native children.
- `@expo/ui`, Reanimated, and Worklets are required peers.
- The permission, named-window, state, edge-hide, renderer-registration, and preview behavior stays intact.
- Documentation has one unversioned SDK 58 path and complete copy-paste examples.

## Review Focus

- Fast refresh or module destruction must not leave the overlay service dispatching through a stale native module instance; cover this in the native source contract and emulator reload test in Tasks 2 and 6.
- `NativeWindow` must default `matchContents` without overriding an explicit `false`; cover both cases in Task 3.
- Invalid React Native size values (`NaN` and infinities) must not be animated into styles; cover this in Task 3.
- A package build must not retain any removed window-container or packaged-renderer export; cover source and generated declarations in Tasks 3 and 6.
- The docs build must contain no SDK 55/56/57 selector or `/versions/` link; cover this in Task 5.
