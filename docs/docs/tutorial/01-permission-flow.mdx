# Request permission

Android requires the user to grant draw-over-apps permission in system settings. `requestPermission()` opens that screen; it cannot approve the permission for the user.

Copy this component into your app:

```tsx
import { useEffect, useState } from 'react';
import { AppState, Button, Text, View } from 'react-native';
import { canDrawOverlays, requestPermission } from 'expo-draw-over-apps';

export function OverlayPermission() {
  const [granted, setGranted] = useState(canDrawOverlays());

  useEffect(() => {
    const subscription = AppState.addEventListener('change', (state) => {
      if (state === 'active') {
        setGranted(canDrawOverlays());
      }
    });

    return () => subscription.remove();
  }, []);

  return (
    <View style={{ gap: 12 }}>
      <Text>{granted ? 'Overlay permission granted' : 'Overlay permission required'}</Text>
      {!granted && (
        <Button
          title="Open overlay settings"
          onPress={() => void requestPermission()}
        />
      )}
    </View>
  );
}
```

Re-check permission when the app becomes active because Android returns the result through system settings, not a normal runtime-permission dialog.

Continue with either [ReactNativeWindow](./react-native-window) or [NativeWindow](./native-window).
