# API guide

The [generated public API](/docs/public-api/) contains every signature and prop type. The groups below are the common application flow.

## Window roots

- `ReactNativeWindow` — application-owned React Native children, with animated numeric sizing.
- `NativeWindow` — application-owned Expo UI Jetpack Compose children in a direct `Host`.

These are the only exported window roots. There is no packaged renderer or compatibility container.

## Permission

- `canDrawOverlays()`
- `requestPermission()`

## Renderer registration

- `setBubbleRenderer(renderer)`
- `setBubbleRendererForBubble(bubbleId, renderer)`
- `BubbleRendererProps`

Prefer per-bubble registration and pass `null` during effect cleanup.

## Window lifecycle

- `showBubble(bubbleId?, options?)`
- `closeBubble(bubbleId?)`
- `closeAllBubbles()`
- `isBubbleVisible(bubbleId?)`
- `openApp()`
- `setEdgeHideEnabled(enabled, bubbleId?)`

`hideBubble()` and `hideAllBubbles()` remain deprecated aliases for source compatibility; new code should use the close APIs.

## Visibility state

- `useBubbleState(bubbleId?)`
- `useAllBubbleStates()`
- `getAllBubbleStates()`
- `refreshBubbleState(bubbleId?)`
- `subscribeToBubbleState(listener)`

## Numeric shared values

- `setOverlaySharedValue(valueKey, value, source?)`
- `useOverlaySharedValueState(valueKey?)`
- `useAllOverlaySharedValueStates()`
- `getOverlaySharedValueState(valueKey?)`
- `getAllOverlaySharedValueStates()`
- `refreshOverlaySharedValueState(valueKey?)`
- `refreshAllOverlaySharedValueStates()`
- `subscribeToOverlaySharedValueState(listener)`

## IDs

Bubble IDs and shared-value keys are normalized before reaching Android. Unsupported characters become `-`, repeated dashes collapse, and values are capped at 80 characters. Use values such as `chat-head` or `timer-window`; do not use emails, tokens, or private user data.
