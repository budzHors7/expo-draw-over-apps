# Limitations

## Android only

The module creates Android application overlay windows. It does not provide iOS overlay behavior.

## Development or production build required

Expo Go cannot load this package because it includes native Android code. Rebuild your app after installing or upgrading it.

## Permission is controlled by the user

Android grants `SYSTEM_ALERT_WINDOW` through system settings. Your app can open the correct settings screen and detect the current result, but it cannot approve the permission.

## Expo Modules 2.0 is still evolving

The SDK 58 release uses the new Expo Modules API. Follow SDK 58-compatible Expo package versions and rebuild native projects after dependency changes.

## Native content follows Compose semantics

`NativeWindow` is an Expo UI `Host`, so its children must be `@expo/ui/jetpack-compose` components unless you explicitly introduce `RNHostView`. Sizing and animation belong to Compose modifiers, not React Native styles.

## IDs and shared values are not storage

Bubble IDs and shared-value keys cross the JavaScript/native boundary. Keep them static and non-sensitive. Shared values store finite numbers only; use your application store for private or structured data.
