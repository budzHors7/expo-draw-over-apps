# Window controls

Named windows can be positioned, moved, edge-hidden, inspected, and closed independently.

## Predefined locations

Use `location` when the window should snap to one of nine screen positions while remaining completely visible.

```tsx
await showBubble('player', { location: 'top-left' });
await showBubble('player', { location: 'top-center' });
await showBubble('player', { location: 'top-right' });
await showBubble('player', { location: 'center-left' });
await showBubble('player', { location: 'center' });
await showBubble('player', { location: 'center-right' });
await showBubble('player', { location: 'bottom-left' });
await showBubble('player', { location: 'bottom-center' });
await showBubble('player', { location: 'bottom-right' });
```

`top` and `bottom` are shorter aliases for `top-center` and `bottom-center`.

An explicit coordinate overrides the matching preset axis. This keeps the preset's other axis:

```tsx
await showBubble('player', { location: 'bottom-left', x: 120 });
```

## Coordinates

`x` and `y` are optional physical screen pixels measured from the display's top-left corner. You may provide either axis independently.

```tsx
await showBubble('player', { x: 48, y: 180 });
await showBubble('player', { x: 240 });
await showBubble('player', { y: 120 });
```

Android clamps supplied coordinates to the available display bounds so the window remains reachable. Omitting coordinates and `location` preserves the module's existing placement behavior.

## Move an open window

Calling `showBubble` for an already-visible ID repositions that window immediately. This makes in-window “move” actions straightforward:

```tsx
<Pressable onPress={() => void showBubble(bubbleId, { x: 240, y: 120 })}>
  <Text>Move window</Text>
</Pressable>
```

An explicit position also clears an edge-docked offset before applying the new coordinates.

## Close and edge hide

```tsx
import {
  closeAllBubbles,
  closeBubble,
  isBubbleVisible,
  setEdgeHideEnabled,
  showBubble,
} from 'expo-draw-over-apps';

setEdgeHideEnabled(true, 'player');
await showBubble('player', { edgeHideEnabled: true, x: 48, y: 180 });

if (isBubbleVisible('player')) {
  closeBubble('player');
}

closeAllBubbles();
```

Closing releases the native overlay surface and its React root. Prefer `closeBubble` over the deprecated `hideBubble` compatibility alias.
